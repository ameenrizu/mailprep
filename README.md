# MailPrep Pro

A PyQt5 desktop tool built for VFX I/O workflows to generate clean, Gmail-safe delivery mail previews from folder structures.

## Preview

![App Screenshot](screenshots/main.png)


## Features

- Folder structure parsing
- Sequence detection with missing frames
- Gmail-safe HTML mail generation
- Submission notes system
- Suspicious name detection
- Dark/Light theme
- Copy to clipboard (Rich + HTML)
